## 🚀 COMMAND RÀPIDA (CHEATSHEET)

### Copiar tots els prompts a fitxer

```bash
cd imatges/
find . -name "*.md" -type f | xargs grep -l "PROMPT" > prompts.txt
```

### Generar imatge amb Midjourney inline

```bash
# Copiar prompt de fitxer → Enviar a Midjourney
# /imagine [PROMPT_HERE]
```

### Testejar aspecte ratio

```bash
# Verificar dimensions
identify -format "%wx%h\n" generada-image.jpg
# Esperat: 375×667 (9:16) o 375×500 (3:4) o 48×48 (1:1)
```

### Optimitzar JPG

```bash
convert input.jpg -resize 375x667 -quality 70 output.jpg
convert input.jpg -resize 375x500 -quality 75 output.jpg
```

### Copiar a webapp

```bash
cp output.jpg /path/to/scaperoom/public/images/[category]/
```
