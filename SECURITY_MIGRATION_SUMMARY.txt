WHAT CHANGED
================================================================================

REMOVED: 5 overly permissive policies
  ✗ allow_insert_teams
  ✗ allow_insert_players
  ✗ allow_insert_sessions
  ✗ allow_insert_results
  ✗ master_insert_own_sessions

ADDED: 25 strict RLS policies
  Teams (3): SELECT own, UPDATE own (immutable code/variant)
  Players (3): SELECT own record + teammates, UPDATE own only
  Sessions (5): SELECT own (read-only), all writes BLOCKED
  Attempts (4): SELECT own, INSERT own, UPDATE/DELETE BLOCKED
  Results (3): SELECT own, all writes BLOCKED (API-only)
  Master Sessions (4): SELECT own only
  Solutions (4): Completely hidden from all except service_role
  Audit Log (2): Service role only

ADDED: Audit system
  New table: audit_log (timestamped change tracking)
  3 new triggers: Automatic logging of sessions, attempts, results changes
  Compliance: Full audit trail for debugging & security investigation
