## Contingut del Cartell

### Secció 1: Títol i Context (Part Superior)

```
CAMINS DE PLANES BONES

Temps de pas a peu, de nit i amb fanal.
Cada ratlla és un quart d'hora.
```

Tipografia: **negra sobre pergamí crem**, estil descriptor de ruta.

### Secció 2: Mapa Esquemàtic (Part Central Major — 60% del cartell)

**Mapa de camins amb nodes i distàncies:**

Nodes (masies i cruïlles):
- La Guixa (centre/sud)
- Cruïlla (nord-est)
- Pont Vell (nord)
- Gual de la riera (nord-est, marcat com "INTRANSITABLE")
- Mas de l'Om (nord-oest)
- Camps de blat (sud-east, marcat com "SEM RASTRE")
- Molí Vell (sud)

Línies de camí amb **nombres de quarts** entre nodes:
```
La Guixa ↔ Cruïlla: 4 quarts
Cruïlla ↔ Pont Vell: 3 quarts
Pont Vell ↔ La Guixa: 3 quarts
Pont Vell ↔ Mas de l'Om: 4 quarts
...etc
```

Estil visual: **mapa esquemàtic en perspectiva de pàgel/pícaro medieval**, amb casetes petites i camins marcats amb línies puntejades.

### Secció 3: Taula de Temps (Part Inferior Dreta)

**TAULA DE TRAMS I TEMPS**

| Tram | Quarts d'hora |
|------|---------------|
| Cruïlla ↔ La Guixa | 4 |
| Cruïlla ↔ Pont Vell | 3 |
| Cruïlla ↔ Gual | 2 |
| Pont Vell ↔ Mas de l'Om | 4 |
| Pont Vell ↔ La Guixa | 3 |
| Gual ↔ Mas de l'Om | 3 |
| La Guixa ↔ Camps de blat | 2 |
| Camps de blat ↔ Mas de l'Om | 2 |
| La Guixa ↔ Molí Vell | 3 |
| Molí Vell ↔ Mas de l'Om | 4 |

Tipografia: **16 punts**, taula clara i fàcil de consultar.

### Secció 4: Advertència dels Jurats (Bandera Lateral)

```
AVÍS DELS JURATS, MAIG DE 1705

La riera va crescuda: EL GUAL NO ES PASSA.

Qui travessi els blats a punt de segar pagarà el mal fet:
de nit no hi passa ningú sense deixar rastre, i NO N'HI HA.
```

Ubicació: **banda lateral esquerra**, destacada en rojo o negreta.

Tipografia: **14 punts**, text seriós i advertència clara.

## Prompt per Generar la Imatge

**Estil i Ambientació:**

```
Medieval Catalan path map, 1705. Create a schematic network map of 
Planes Bones showing 7 key locations (La Guixa, Cruïlla, Pont Vell, 
Gual, Mas de l'Om, Camps de blat, Molí Vell) connected by dashed paths. 
Label each path segment with travel time in quarter-hours (4, 3, 2, etc). 
Add small illustrations: cottage icons, trees, a river crossing (marked 
INTRANSITABLE in red), wheat field (marked no footprints). Include a 
warning banner top-left from the village magistrates about the swollen 
stream and impassable paths. Add time reference table (bottom-right) 
listing all tram durations. Color: cream parchment, brown ink, red 
warnings. Dimensions: A1 (594×841 mm).
```

**Detalls Visuals:**

- **Mapa:** Esquemàtic, no geogràfic realista (estil medieval)
- **Nodes:** Símbol de caseta simple per a cada ubicació
- **Camins:** Línies puntejades, números interiors
- **Gual:** Marcat amb "X" o "INTRANSITABLE" en rojo
- **Blats:** Dibuix de grans, "SEM RASTRE" en rojo
- **Avís:** Banner o bandera vermella amb text blanc
- **Taula:** Quadrícula clara a banda dreta o baix

---

## Elements Clau

✓ Mapa esquemàtic legible amb tots els nodes
✓ Nombres de quarts clarament visibles (14–18 punts)
✓ Gual i blats marcats com a "intransitables/sense rastre"
✓ Taula de durades accessible (no perduda en mapa)
✓ Avís dels jurats prominent i alarmant
✓ QR codi gran i escanejable
✓ Contrast alt per llegibilitat a la llum natural
✓ Escala visual coherent

---

## Notes de Producció

1. **Impressió:** Color, qualitat 300 dpi
2. **Tamany:** A1 (594×841 mm) per a llegibilitat de mapa
3. **Protecció:** Laminat mate (protegir contra vent i rosada)
4. **Fixació:** 4 suports metàl·lics ben assegurats (A1 és gran i pesat)
5. **Ubicació:** Vora del camí principal, no obstructor
6. **Revisió:** Verificar que nombres de quarts són llegibles a 1 metre

## Alternativa: Mapa en Terreny Real

**Opció avançada:** Marcar físicament els nodes i camins al terreny real amb:
- Marcadors reflectants en casetes/arbres
- Número de quarts pintat al terra o en pals

**Avantatge:** Immersió total, els jugadors caminen els camins reals.
**Inconvenient:** Logística complexa, preparació del terreny, neteja posterior.

**Recomanació:** Cartell A1 + marcadors simples (més simple de mantenir).
