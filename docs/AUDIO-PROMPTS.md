## Recording Checklist

### Before Recording

- [ ] Quiet room (no traffic, AC hum, or background noise)
- [ ] Microphone: USB condenser mic (Audio-Technica AT2020, Blue Yeti, or similar) or professional recording setup
- [ ] Test levels: Aim for -12dB to -6dB peak (leave headroom)
- [ ] Sample rate: 44.1kHz or 48kHz
- [ ] Mono or Stereo: Mono is fine for voice and effects
- [ ] Recording software: Audacity (free), GarageBand, or Adobe Audition

### During Recording

- [ ] Do 2–3 takes of each voice clip
- [ ] Keep files under 100KB each (MP3, 192kbps bitrate recommended)
- [ ] Save as WAV first, then export to MP3
- [ ] Label files clearly: `bernat-act1`, `mossen-act2`, `emissari-act3`, etc.
- [ ] Keep background noise minimal

### Post-Production

- [ ] Remove silence at start/end (0.5s fade-in/out)
- [ ] Normalize audio to -3dB
- [ ] Check for pops/clicks and remove
- [ ] Compress gently for consistent levels
- [ ] Add slight reverb if recording in a dead room (optional)

### Final Check

- [ ] All 9 voice files in correct folder (`public/audio/voices/{actor}/`)
- [ ] All 4 effect files in correct folder (`public/audio/effects/`)
- [ ] Each file named correctly: `{actor}-act{1-3}.mp3` or `{effect-name}.mp3`
- [ ] All files MP3 format, 44.1kHz, <100KB each
- [ ] No corruption: Play each file in browser DevTools
