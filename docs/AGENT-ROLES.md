#### Fase 0 (2h)
```
TASQUES:
1. Crea Next.js app amb TypeScript
   → npm create-next-app traidor-guixa --typescript --tailwind --eslint

   → supabase init
   → supabase start

   → NEXT_PUBLIC_SUPABASE_URL
   → NEXT_PUBLIC_SUPABASE_ANON_KEY
   → SUPABASE_SERVICE_ROLE_KEY
   → MASTER_PIN (ex: 123456)
   → MASTER_SESSION_SECRET
   → PASS_SECRET
   → NEXT_PUBLIC_APP_URL
   
5. Setup deploy (Vercel)
   → vercel link
   → vercel deploy
   
6. Estructura carpetes
   ```
   app/
     (player)/
       e/[code]/        → entry QR equip

   ```

7. Commit + push + notify
   → git commit -m "chore: setup phase 0 - next.js, supabase, vercel"
   → git push -u origin phase/0-setup
   → TaskUpdate(MASTER, "Phase 0: COMPLETED ✓")

- None (first phase)

```

#### Fase 1 (4h)
```
TASQUES:
1. Crear migracions SQL (supabase/migrations/)
   → 001_init_schema.sql — totes les taules
   → 002_rls.sql — policies
   → 003_content.sql — INSERT contingut privat
   
   Taules clau:
   - sessions (id, name, status, started_at, etc.)
   - teams (id, session_id, name, color, join_code)
   - players (id, team_id, name)
   - team_stations (team_id, station_id, status, game_state)
   - attempts (id, team_id, station_id, answer, correct)
   - hints_used (id, team_id, level, given_by)
   - team_evidences (team_id, evidence_id, source)
   - accusations (team_id, suspect_id, evidence_ids, correct)
   - score_events (id, team_id, delta, reason)
   - messages (id, session_id, team_id, body)
   - passes (id, team_id, scanned_at, action)
   - events (id, session_id, team_id, type, payload)

2. Enable RLS (Row Level Security)
   → ALTER TABLE sessions ENABLE ROW LEVEL SECURITY;
   → CREATE POLICY "Players see only their session"
   → CREATE POLICY "Master can see all" (usando service role)

3. Load private content
   → INSERT INTO solutions_private (station_id, answer, ...)
   → INSERT INTO hints (station_id, level, ...)
   → INSERT INTO traitor_metadata (...)

4. Generate types
   → supabase gen types typescript --local > lib/db.types.ts
   → Crea lib/db.ts amb Supabase client tipat

5. Commit + push
   → git commit -m "feat: database schema, rls, content"
   → git push -u origin phase/1-database

BLOCKERS:
- Wait for Phase 0 merge to main

SUCCESS CRITERIA:
✓ supabase db push executes without errors
✓ All tables created with correct columns
✓ RLS policies active (verify with console)
✓ lib/db.types.ts autogenerated
✓ Content tables populated
✓ Types can be imported in other agents' code
```

- Phase 4 complete (jocs)

SUCCESS CRITERIA:
✓ Login màster funciona (PIN correcte)
✓ Dashboard mostra equips en temps real

### Estructura Genèrica Joc

Tota joc segueix aquesta interfície (definida a `components/games/index.ts`):

```ts
export interface GameProps {
  stationId: string
  content: PublicStationContent  // narrativa, dades públiques
  sharedState: unknown           // estado compartit equip
  setSharedState: (s: unknown) => void
  submit: (answer: unknown) => Promise<SubmitResult>
  solved: boolean
}

export interface SubmitResult {
  correct: boolean
  message?: string
  score?: number
}
```
